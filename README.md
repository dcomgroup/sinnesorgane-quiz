# Sinnesorgane Lernquiz

52 Lernkarten zu Auge, Nase, Haut und Ohr mit Bildern und Wiederholungsalgorithmus.

## Veröffentlichung

1. Die Datei `sinnesorgane_quiz_kompakt.zip` im Hauptverzeichnis dieses Repositorys hochladen (nicht entpacken).
2. Unter **Settings → Pages → Build and deployment → Source** die Option **GitHub Actions** auswählen.
3. Unter **Actions → Publish learning app** den erfolgreichen Lauf prüfen.

Web-App: https://dcomgroup.github.io/sinnesorgane-quiz/

Der Lernstand wird lokal im Browser gespeichert und nicht zwischen Geräten synchronisiert.
